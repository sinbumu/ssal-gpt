03 / SNS·폼 로그인

마지막 확인은 해당 브라우저 프로필의 관찰 결과입니다. 다른 프로필과 공유하지 않으며 하루가 지나면 재확인을 권장합니다.

선택한 전용 브라우저에서 직접 로그인합니다. 인증 중에는 화면을 AI에 보내지 않습니다.

두 브라우저는 로그인 저장소가 별개입니다. 바꾸면 현재 전용 창을 닫고, 기존 로그인 저장소는 보관합니다. 평소 쓰는 Chrome의 로그인은 가져오지 않습니다.

자동 작업용 새 탭은 배경에서 열고, 직접 ‘브라우저 열기·로그인’을 누르면 창을 앞으로 가져옵니다. 다만 브라우저 최초 실행이나 사이트가 직접 여는 탭·팝업은 맥 화면을 앞으로 가져올 수 있습니다.

연결된 계정으로 선택한 게시물의 댓글·좋아요·팔로우를 처리합니다. 작업마다 대상과 게시 문구를 한 번에 확인합니다. 서비스 공식 승인과는 별개이며, 계정 경고·추가 인증이 나타나면 멈춥니다.

네이버는 홈 화면에서 로그인 여부를 확인하세요. 로그인할 때 ‘로그인 상태 유지’를 직접 체크해야 창을 닫은 뒤에도 유지될 수 있습니다.

유튜브가 브라우저 로그인을 거부한다면

정식 Chrome을 선택해 호환성을 확인할 수 있지만, Google은 자동화 브라우저의 로그인을 거부할 수 있습니다.

이 경로는 직접 참여용입니다. 일반 브라우저의 로그인은 에이전트와 공유되지 않으며, 이 창은 자동 조작하지 않습니다.

04 / 연결 동작 확인

가상 이벤트에서 화면 읽기·퀴즈·입력·접수를 검사합니다. 실제 경품이 없으며 모델 사용량은 발생합니다.

기존 Chromium 브라우저 직접 연결

직접 준비한 로컬 디버깅 브라우저의 탭 하나를 선택합니다. 평소 Chrome 프로필이나 쿠키를 복사하지 않습니다. Chrome 136 이상은 기본 프로필의 디버깅을 허용하지 않으므로 별도 사용자 데이터 폴더가 필요합니다. 이 연결은 선택한 탭 한 개만 사용하며 별도 조사 탭과 여러 작업 병행은 전용 브라우저 모드에서 지원합니다.

연결 해제는 ‘전용 브라우저 정상 종료’로 처리합니다. 사용자의 브라우저 창은 닫지 않으며, 재시작 후 자동으로 다시 연결하지 않습니다.

07 · 예약·운영

서울 시간 기준

앱과 컴퓨터가 켜져 있을 때 실행합니다. 놓친 예약은 한 번만 실행하며, 답변 대기 중인 폼은 별도 탭에 보존합니다.

반복 검색이나 부적합한 출처에서 앱이 다른 출처를 자동으로 고르는 횟수입니다. 공급자의 잔여 사용량과 별개인 앱 제한이며, 새 작업·재개부터 적용합니다. 이미 사용한 횟수는 유지하고 탐색 AI 호출·하루 사용량 한도도 함께 적용합니다.

API 추정 비용 제한

선택한 API 모델의 100만 토큰당 USD 단가를 직접 입력합니다. ChatGPT 크레딧은 환산하지 않습니다. 토큰·추정 비용은 응답 후 집계하므로 마지막 호출만큼 초과할 수 있습니다. 실제 결제 상한은 공급자 설정에서 관리하세요.

저장 공간·보관

일반 관찰 자료는 기간·용량 기준으로 오래된 순서대로 정리합니다. 원문·접수·동의·오류 증거와 진행·미확인 작업은 보호합니다. 과거 용도 미분류 자료도 보존합니다. 응모·사용량·중복 방지 기록은 삭제하지 않습니다.

3072MiB = 3GiB. 보호 자료도 상한에 포함합니다. 정리할 수 있는 자료가 없으면 중요한 증거를 삭제하는 대신 새 관찰을 중단합니다. 자동 정리를 꺼도 용량 상한은 적용됩니다.

캐시는 정상 종료 또는 다음 실행 전에 기준을 넘으면 정리합니다. 실행 중에는 기준을 넘을 수 있습니다. 쿠키·로그인·사이트 저장소와 사용자가 연결한 일반 브라우저는 대상이 아닙니다.

용량을 확인하려면 아래 버튼을 누르세요.

반복 탐색 추가

현재 선택한 AI 연결·모델, 탐색 조건, 브라우저를 사용합니다. 자동 응모 준비를 선택했다면 현재 위임 정책도 함께 저장합니다.

기회 선택 기준

응모 성공 → 토큰 절감 → 시간

자격은 직접 확인한 사실만 저장합니다. 원문의 조건과 정확히 비교할 수 없으면 확인 대상으로 남습니다.

모드를 바꾸면 아래 권장값을 채웁니다. 세부 값을 조정한 뒤 저장하세요. 가입·동의·게시 위임은 별도이며, 실제 필수 과제만 수행합니다.

허용하는 필수 과제
탐색·응모 예산 세부 설정

각 작업의 보고 사용량 기준입니다. 응답 후 집계하므로 마지막 호출만큼 넘을 수 있습니다. 토큰 칸을 비우면 하루 운영 한도만 적용합니다. 후보 전환으로 새 탐색을 시작하면 별도 작업 예산을 사용합니다.

서비스 운영자의 자동 실행 허용 근거 등록

응모 대행 승인과 별개입니다. 해당 서비스가 공개한 허용 또는 운영자로부터 받은 권한이 있는 정확한 대상만 등록합니다. 인스타 브라우저 대행은 위의 사용자 위임 설정과 작업별 승인을 사용하며 공식 허용으로 표시하지 않습니다. YouTube 자동 쓰기는 지원하지 않습니다.
