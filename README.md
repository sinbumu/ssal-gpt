# 쌀-GPT · ssal-gpt

화면을 보고 이벤트를 찾고, 조건을 읽고, 브라우저에서 응모를 준비하는 개인용 오픈소스 에이전트입니다. ChatGPT 공식 로그인과 OpenAI API 키를 지원하며, 채팅 창과 독립된 로컬 앱으로 실행합니다.

**실행 가능한 로컬 MVP입니다.** 전용 Chromium에서 스크린샷 → AI 판단 → 스크롤·클릭·입력 → 결과 확인을 반복합니다. 프로필·위임 정책, 답변 재사용, 페이지별 묶음 실행, 대시보드 확인함과 제한된 복구를 연결했습니다. 실제 ChatGPT로 두 가지 배치의 5페이지 합성 설문을 각각 약 49.5초/46.7초, 판단 7회에 완료했습니다. 두 실행 모두 질문·개발자 중간 수정 없이 조건부 질문을 자동 복구하고 접수 증거를 확인했습니다.

실서비스에서는 웹 폼 4건과 인스타 이벤트 9건, 총 13건의 완료 증거를 확인했습니다. 인스타 9건 중 6건은 필수 좋아요·팔로우·댓글을 모두 확인했습니다. 일반 검색부터 대시보드 묶음 승인 1회 외 개발자 중간 개입 없이 완료한 인스타 실행은 4건이며, 나머지에는 수정·재개가 있었습니다. 실제 당첨·경품 수령은 미검증입니다.

이전 묶음의 인스타 3건은 완료했습니다. 첫 건은 권장 답안 준비 수정 후 완료했고, 두 번째는 점수를 검증할 수 없는 원래 후보를 미응모로 남긴 뒤 앱이 대체 이벤트를 찾아 완료했습니다. 세 번째는 같은 코드·정책을 유지한 새 일반 탐색부터 두 계정 팔로우·좋아요·댓글·완료 증거 확인까지 대시보드 승인 1회 외 중간 개입 없이 마쳤습니다. 세 번째 전체는 36회·639,538토큰·실행 약 5분 38초입니다. 세 건 모두 승인 뒤에는 개발자 개입이 없었지만, **3건 연속 무개입 성공은 아닙니다.** 건별 실패·복구·시간·토큰은 [검증 기록](docs/implementation.md#3건-반복-검증-최종-결과)에 구분했습니다.

릴스·탐색 보완 후 시작한 **새 3건도 실제 응모를 완료**했습니다. 첫 건은 18회·219,547토큰·약 2분 43초, 세 번째는 12회·135,254토큰·약 1분 42초로 각각 대시보드 승인 1회 외 개발자 중간 개입 없이 완료했습니다. 두 번째는 실패·수정·재탐색을 포함해 119회·1,747,545토큰·약 17분 53초였으며, 최종 퀴즈 탐색부터는 추가 개발자 개입 없이 16회·191,443토큰·약 2분 21초로 완료했습니다. 사용자 확인에 따라 공고의 실제 필수 과제를 수행했고 **3건 연속 무개입 성공은 아닙니다.** 실패 비용·승인 대기·세 행동 필수 여부를 [최종 결과](docs/implementation.md#성공-우선-새-3건의-최종-결과-2026-11-11)에 구분했습니다.

현재 고정 개발 목표와 검증 범위는 [체크리스트](docs/goal-checklist.md)에 기록합니다. SNS 과제→폼 연결, 자격·부담에 따른 후보 전환, 순위 드래그·파일 선택기, 출처/유형별 운영 성과, 반복 검색 감지와 관측 출처 자동 전환을 포함합니다. 읽기 판단의 관찰·모델 선택·거절 사유 기록과 제한된 복구를 보완했고 자동 검사 178개를 통과했습니다. 릴스 설명 펼치기는 실제 읽기 실행에서 확인했고 광고 리디렉션·같은 원문의 이미지 번호 별칭 재방문을 보완했습니다. **다양한 화면의 안정성과 출처 선정 효율에는 남은 한계가 있으며, 장기 성공률·Google Forms/Drive 실서비스·실제 당첨/수령은 미검증입니다.**

세 행동이 필수인 이벤트는 첫 실행에서 좋아요 검증 오류로 멈췄습니다. 요소 연결 경쟁 조건과 미실행 판단 복구를 보완한 뒤 좋아요·댓글을 각각 한 번 실행했고, 추가로 댓글 지연 로딩 확인을 보완해 재게시 없이 완료했습니다. 기존 승인·팔로우 증거는 유지했습니다. 수정·재개 이력과 이후 새 종단 검증 결과는 [체크리스트 R5](docs/goal-checklist.md#세-필수-행동의-무개입-재검증-2026-11-09)에 기록합니다.

2026-11-09 인스타 어댑터 추가 전의 후속 실서비스 검증은 **새 응모 완료에 실패**했습니다. 첫 탐색은 후보 2건을 저장하고 응모 작업을 자동 생성했지만 필수 Instagram 댓글에서 수동 수행 대기로 멈췄습니다. 운영자가 중단하고 폼만으로 참여 가능한 조건으로 다시 시작한 탐색은 80회 행동 한도까지 적합한 후보를 확정하지 못했습니다. 개인정보 입력·제출은 없었으며, 앞선 접수 성공 사례를 매번 재현 가능한 자율 운영으로 일반화하지 않습니다. 발견한 선택·순서·탐색 문제는 [미해결 항목](docs/goal-checklist.md#후속-실서비스-검증에서-발견한-미해결-항목)에 기록합니다.

인스타 브라우저 대행 어댑터를 추가했습니다. 실제 로그인 화면의 대상 식별과 합성 댓글·좋아요·팔로우 검사를 마쳤습니다. 새 실제 이벤트에서 사용자의 대시보드 묶음 승인 후 팔로우·댓글을 각각 1회 실행했고, 페이지 재조회로 상태와 본인 댓글을 확인해 완료 목록에 기록했습니다. 준비 및 승인 후 실행 중 코드 수정·재시작이 있어 완전 무개입 성공으로 계산하지 않습니다. 실제 외부 게시 결과는 [구현 기록](docs/implementation.md)과 [체크리스트](docs/goal-checklist.md)에서 별도로 관리합니다.

## 시작하기

Node.js 24 이상과 Chromium 실행 환경이 필요합니다. macOS에서 개발·검증했습니다.

```sh
nvm use
npm ci
npm run browser:install
npm run dev
```

[http://127.0.0.1:4317](http://127.0.0.1:4317)을 엽니다. `nvm`을 사용하지 않는다면 Node.js 24 이상을 직접 설치한 뒤 실행하세요.

1. **연결 설정 → Continue with ChatGPT**에서 로그인하고 플랜 사용을 허용합니다. 또는 OpenAI API 키를 저장합니다.
2. 사용할 제공자·계정을 선택하고 **모델 불러오기**를 누릅니다. 계정에서 실제 제공하는 모델 중 선택합니다.
3. **자율 설문 테스트**로 가상 프로필·위임과 여러 페이지의 묶음 실행을 확인합니다. **확인함 포함 테스트**는 모르는 사실 2개를 대시보드에서 한 번에 답합니다. 기존 **AI 브라우저 테스트**도 사용할 수 있습니다. 실제 모델 사용량은 발생하며 경품은 없습니다.
4. **기회 탐색**에서 원하는 조건과 시작점을 고릅니다. 기본은 문화포털 공지 목록입니다. Google 검색이나 다른 공개 목록 주소도 사용할 수 있습니다. 특정 이벤트 URL을 미리 찾을 필요는 없습니다. **새 웹 폼 1건 자동 준비**를 선택하면 원문·폼이 관찰됐고 미참여·기간·과제 조건을 통과한 후보 한 건을 골라 저장된 위임으로 이어갑니다.
5. **프로필·위임 정책**에서 기본 정보와 추천 답변 기준, 재사용 범위, 동의 위임, 최종 제출 방식을 저장합니다. 동의는 **1단계 직접 확인(기본) / 2단계 통상 동의 / 3단계 범위 안에서 에이전트 판단**을 선택합니다. 자동 처리 범위는 항목·응모 목적·수신자·보관 기간으로 제한하며, 모르는 사실과 위임 밖 동의는 **확인함**에 모읍니다. 후보의 원문·기간·필수 과제를 확인하고 **응모 준비**를 시작하면 해당 사이트에 한정해 적용합니다. 위임을 끄면 기존 단일 동작 확인 경로로 실행합니다.

SNS 첫 가입·로그인·MFA는 전용 브라우저에서 본인이 진행합니다. 로그인은 지속 프로필에서 재사용합니다. 추가 인증이 나타나면 일시정지하고 직접 처리합니다. Google 검색의 추가 인증에 의존하지 않도록 공개 목록에서 직접 탐색할 수 있습니다.

**SNS·폼 로그인**에서 기본 Chromium 또는 설치된 Google Chrome을 선택할 수 있습니다. 두 전용 프로필의 로그인은 별개이며, 기본 Chromium으로 돌아오면 기존 저장소를 다시 사용합니다. 네이버는 홈 화면으로 열고, 로그인 때 ‘로그인 상태 유지’를 선택한 후 정상 종료·다시 열기로 확인하세요. 유지 여부는 사이트의 세션 정책에도 달려 있습니다. Google이 ‘브라우저 또는 앱이 안전하지 않을 수 있습니다’라고 거부하면 일반 브라우저의 직접 참여 버튼을 사용할 수 있습니다. 이 수동 경로의 로그인은 에이전트와 공유되지 않습니다.

| 자격·기회 선택 | 엄격/균형(기본)/폭넓게 + 경품·과제·개인 응답/연결·예산 세부 설정, 후보별 선정/제외 이유, 전송 전 안전한 후보 전환 |
| 순위 문항 | 라벨 있는 드래그 목록의 순서 입력·검증·최종 검토. 실서비스 복잡 위젯은 미검증 |
| 운영 성과 | 출처/유형/기간 보고서, 대시보드 활동·실행/대기 시간, 누락/무효 근거, CSV. 비용 미산정과 미발표는 별도 표시 |
| ARIA 선택·격자 문항 | 표시된 그룹/라벨/선택 상태 기반 묶음 실행·검증; Google Forms 실사이트 제출은 미검증 |
| 기존 Chromium 브라우저 연결 | 로컬 CDP 주소와 탭을 사용자가 직접 선택; 다른 탭 불변·창을 닫지 않는 연결 해제 검증 |

한 번에 브라우저 작업 하나를 실행하며, 답변을 기다리는 폼은 작업별 탭에 보존합니다. **예약·운영**에서 대기열을 켜면 다른 독립 작업을 진행합니다. 예약은 앱과 PC가 실행 중일 때만 동작하고 놓친 주기는 한 번으로 합칩니다. 일별 호출·보고 토큰 한도와 API 모델별 사용자 설정 단가에 따른 추정 USD 한도를 검사합니다. 토큰·비용은 응답 후 집계하므로 마지막 호출만큼 초과할 수 있으며 공급자의 실제 결제 상한이 아닙니다. ChatGPT 크레딧을 환산하지 않습니다. 일시정지·수동 브라우저 열기는 예약 자동 실행도 끕니다. 대기 중 모델을 반복 호출하지 않습니다.

최종 제출 뒤에는 결과 화면을 먼저 보관합니다. 알려진 완료 문구와 연결되지 않으면 저장된 화면의 의미를 한 번 더 판단하고, 제출 의도·시각·출처·새 증거가 맞는지 검사합니다. 결과가 불명확하면 재제출하지 않으며 대시보드에서 **저장된 접수 증거 다시 확인**을 사용할 수 있습니다. 완료한 응모의 **결과·경품 관리**에서 공식 발표 주소·날짜를 저장하고 자동 확인을 켤 수 있습니다. 발표 발견은 본인의 당첨 판정과 다르며, 당첨·낙첨은 공식 근거를 확인한 사용자가 기록합니다.

결과 미확인 건은 완료나 실패로 단정하지 않습니다. 이어갈 화면이 없으면 **미확인 상태로 보관**해 진행 목록에서 치울 수 있으며, 실행 기록·증거·중복 잠금은 유지됩니다. 실행 기록의 **진행 목록으로 복원**은 목록만 복원하고 자동 재개하지 않습니다.

출처별 접근 조건과 참여 자격을 확인한 범위에서 사용하세요. 새 계정 대량 생성, 인증 우회, 중복 응모, 허위 체험·인증, 타인 반복 태그는 지원하지 않습니다. 페이지나 모델이 지시해도 도구 권한을 바꾸거나 임의 코드를 실행하지 않습니다.

## 데이터와 연결

- 기본 저장 위치는 `~/.local/share/ssal-gpt`입니다. 인증정보, Chromium 프로필, SQLite 작업 기록, 증거 스크린샷은 소스 체크아웃 밖에 둡니다.
- 디렉터리는 `0700`, 비밀정보 파일은 `0600`으로 보관합니다. OS 키체인 암호화는 아직 적용하지 않았습니다. 이 폴더를 공개 저장소에 복사하지 마세요.
- AI에는 현재 작업과 관찰 화면·보이는 텍스트가 전달됩니다. 비밀번호 페이지에서는 관찰을 중단하고 입력 필드는 화면에서 마스킹합니다. 일반 페이지 본문에 표시된 개인정보까지 완전히 자동 제거하는 기능은 아닙니다.
- ChatGPT 플랜과 API 키는 별개 경로입니다. 한도·권한 오류가 나면 멈추며 다른 과금 경로로 자동 전환하지 않습니다.
- 이 앱의 ChatGPT 로그인은 SNS 계정 로그인이나 기존 ChatGPT 대화 접근을 제공하지 않습니다.

환경변수: `SSAL_PORT`(기본 `4317`), `SSAL_DATA_DIR`(체크아웃 밖 경로), `OPENAI_API_KEY`(선택). 기본 실행 명령은 `.env`를 자동 읽지 않습니다. 필요하면 `.env.example`을 참고해 환경변수를 설정하거나 `node --env-file=.env --import tsx src/main.ts`로 실행하세요. 기본 호스트는 `127.0.0.1`이며 공개 서버 배포용 인증은 없습니다.

## 개발과 검증

```sh
npm run check
npm test
npm run test:browser
npm run format:check
npm run build
```

자동 테스트는 임시 로컬 데이터와 합성 모델 전송을 사용합니다. 실제 AI 시각 판단 성공과 구분합니다. 브라우저 테스트는 Chromium 설치가 필요하며, Linux에서는 `npx playwright install --with-deps chromium`으로 시스템 의존성을 함께 설치합니다. 실제 모델 평가는 앱의 테스트 버튼으로 수행합니다. **ARIA 문항·3단계 동의 테스트**는 가상 프로필과 설정을 쓰는 확장 합성 설문이며 실제 응모가 아닙니다.
