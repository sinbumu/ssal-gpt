03 / SNS·폼 로그인

선택한 전용 브라우저에서 직접 로그인합니다. 인증 중에는 화면을 AI에 보내지 않습니다.

두 브라우저는 로그인 저장소가 별개입니다. 바꾸면 현재 전용 창을 닫고, 기존 로그인 저장소는 보관합니다. 평소 쓰는 Chrome의 로그인은 가져오지 않습니다.

네이버는 홈 화면에서 로그인 여부를 확인하세요. 로그인할 때 ‘로그인 상태 유지’를 직접 체크해야 창을 닫은 뒤에도 유지될 수 있습니다.

유튜브가 브라우저 로그인을 거부한다면

정식 Chrome을 선택해 호환성을 확인할 수 있지만, Google은 자동화 브라우저의 로그인을 거부할 수 있습니다.

이 경로는 직접 참여용입니다. 일반 브라우저의 로그인은 에이전트와 공유되지 않으며, 이 창은 자동 조작하지 않습니다.
