03 / SNS·폼 로그인

선택한 전용 브라우저에서 직접 로그인합니다. 인증 중에는 화면을 AI에 보내지 않습니다.

두 브라우저는 로그인 저장소가 별개입니다. 바꾸면 현재 전용 창을 닫고, 기존 로그인 저장소는 보관합니다. 평소 쓰는 Chrome의 로그인은 가져오지 않습니다.

네이버는 홈 화면에서 로그인 여부를 확인하세요. 로그인할 때 ‘로그인 상태 유지’를 직접 체크해야 창을 닫은 뒤에도 유지될 수 있습니다.

유튜브가 브라우저 로그인을 거부한다면

정식 Chrome을 선택해 호환성을 확인할 수 있지만, Google은 자동화 브라우저의 로그인을 거부할 수 있습니다.

이 경로는 직접 참여용입니다. 일반 브라우저의 로그인은 에이전트와 공유되지 않으며, 이 창은 자동 조작하지 않습니다.

04 / 연결 동작 확인

가상 이벤트에서 화면 읽기·퀴즈·입력·접수를 검사합니다. 실제 경품이 없으며 모델 사용량은 발생합니다.

기존 Chromium 브라우저 직접 연결

직접 준비한 로컬 디버깅 브라우저의 탭 하나를 선택합니다. 평소 Chrome 프로필이나 쿠키를 복사하지 않습니다. Chrome 136 이상은 기본 프로필의 디버깅을 허용하지 않으므로 별도 사용자 데이터 폴더가 필요합니다. 이 연결은 선택한 탭 한 개만 사용하며 별도 조사 탭과 여러 작업 병행은 전용 브라우저 모드에서 지원합니다.

연결 해제는 ‘전용 브라우저 정상 종료’로 처리합니다. 사용자의 브라우저 창은 닫지 않으며, 재시작 후 자동으로 다시 연결하지 않습니다.

07 · 예약·운영

서울 시간 기준

앱과 컴퓨터가 켜져 있을 때 실행합니다. 놓친 예약은 한 번만 실행하며, 답변 대기 중인 폼은 별도 탭에 보존합니다.

API 추정 비용 제한

선택한 API 모델의 100만 토큰당 USD 단가를 직접 입력합니다. ChatGPT 크레딧은 환산하지 않습니다. 토큰·추정 비용은 응답 후 집계하므로 마지막 호출만큼 초과할 수 있습니다. 실제 결제 상한은 공급자 설정에서 관리하세요.

반복 탐색 추가

현재 선택한 AI 연결·모델, 탐색 조건, 브라우저를 사용합니다. 자동 응모 준비를 선택했다면 현재 위임 정책도 함께 저장합니다.

기회 선택 기준

자격은 직접 확인한 사실만 저장합니다. 원문의 조건과 정확히 비교할 수 없으면 확인 대상으로 남습니다.

서비스 운영자의 자동 실행 허용 근거 등록

응모 대행 승인과 별개입니다. 해당 서비스가 공개한 허용 또는 운영자로부터 받은 권한이 있는 정확한 대상만 등록합니다. Instagram·YouTube 소비자 계정 쓰기는 이 버전에서 자동 실행 경로가 검증되지 않아 등록해도 직접 수행으로 남습니다.
