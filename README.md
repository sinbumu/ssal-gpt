# 쌀-GPT · ssal-gpt

브라우저 화면을 읽고 스크롤·클릭·입력을 수행하며, 이벤트 탐색부터 응모·경품 수령 확인까지 진행하는 개인용 오픈소스 에이전트.

현재는 설계 단계입니다. 실행 가능한 앱, SNS 연동, 실제 자동응모 기능은 아직 구현하지 않았습니다.

## 확정한 방향

- ChatGPT 로그인으로 플랜 사용량을 사용하는 공식 연동과 OpenAI API 키 연동을 모두 지원한다. ChatGPT 로그인은 첫 MVP의 필수 요구사항이다.
- 화면 관찰 → 판단 → 브라우저 조작 → 결과 재관찰의 반복 실행을 첫 MVP에 포함한다. API 연결과 체크리스트만으로 MVP를 완료했다고 보지 않는다.
- 기본 실행 환경은 사용자가 볼 수 있는 전용 Chromium과 지속 프로필이다. 사용자가 연결한 기존 브라우저 지원은 별도 연결 방식으로 확장한다.
- 채팅 화면과 독립된 프로세스로 실행하며, 작업 상태를 저장하고 재시작 후 이어간다.
- 탐색 간격, 실행 시간대, 작업량, 예산, 승인 수준을 설정으로 조정한다.
- 최초 가입·로그인·본인인증은 사용자가 수행하고, 허용된 연동에서 세션을 재사용한다.
- 이벤트를 지원하는 것과 모든 참여 행동을 자동 실행하는 것은 구분한다. 각 행동의 실제 실행 방식과 근거를 표시한다.
- 유효한 응모, 실제 수령·사용 가치, 사람의 시간과 운영비를 측정한다.

## 실행 흐름

스케줄러 → 브라우저로 탐색 → 화면에서 조건 이해 → 중복·자격 검사 → 화면 조작으로 응모 → 결과 재관찰 → 발표·수령 확인

AI는 화면과 관측 정보를 바탕으로 다음 행동을 선택하고, 로컬 브라우저 실행기는 제한된 도구로 행동한다. 서비스 API는 보조 경로이며 공식 API의 기능 유무가 브라우저 실행기의 기능 범위를 결정하지 않는다. 플랫폼의 접근 조건과 사용자 권한은 실행 전 별도로 확인한다.

개인정보, 브라우저 프로필, 인증 토큰, 응모 증거와 쿠폰은 사용자의 로컬 저장소에서 관리한다. 공개 저장소에는 코드, 설계, 합성 예제와 비식별 평가 자료만 둔다.
