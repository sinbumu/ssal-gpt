체크 표시는 위 범위의 **구현과 자동 검증 완료**다. 모든 SNS/폼 위젯의 무인 지원이나 실서비스 완료를 뜻하지 않는다. 외부 서비스의 허용과 로그인은 별도 조건이다.

검사: 단위 35개 + 브라우저 68개 = **103개 통과**. 타입/빌드/포맷 통과. 마지막 보고서·과제 원문 검사 변경 뒤에는 영향받는 검사를 다시 통과했다.

실제 ChatGPT 혼합 합성 실행: 총 6회 호출, 입력/출력 24,011/628 토큰. 좋아요·팔로우·댓글·최종 접수는 합성 서버에서 각각 1회. 테스트 사용자 역할로 정상 앱 경로에서 과제 승인·파일 선택·최종 확인을 제공했다. 실행 중 상태 수정·코드 교체·동작 대행 복구는 없었고, 무인 테스트로 계산하지 않는다. 앞선 실행은 가려진 입력값 때문에 반복 입력해 중단한 실패 사례이며 수정 후 새 실행과 구분한다.

재현: 대시보드 연결 설정의 **SNS·순위·파일 혼합 과제 테스트**. 외부 응모는 없으며 선택한 AI 제공자의 실제 사용량이 발생한다. 자동 검사는 `npm test`, `npm run test:browser`, `npm run check`, `npm run build`, `npm run format:check`로 실행한다.
