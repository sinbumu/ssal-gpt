# 쌀-GPT · ssal-gpt

화면을 보고 이벤트를 찾고, 조건을 읽고, 브라우저에서 응모를 준비하는 개인용 오픈소스 에이전트입니다. ChatGPT 공식 로그인과 OpenAI API 키를 지원하며, 채팅 창과 독립된 로컬 앱으로 실행합니다.

**실행 가능한 로컬 MVP입니다.** 전용 Chromium에서 스크린샷 → AI 판단 → 스크롤·클릭·입력 → 결과 확인을 반복합니다. 프로필·위임 정책, 답변 재사용, 페이지별 묶음 실행, 대시보드 확인함과 제한된 복구를 연결했습니다. 실제 ChatGPT로 두 가지 배치의 5페이지 합성 설문을 각각 약 49.5초/46.7초, 판단 7회에 완료했습니다. 두 실행 모두 질문·개발자 중간 수정 없이 조건부 질문을 자동 복구하고 접수 증거를 확인했습니다.

실서비스에서는 다단계 설문 1건과 Naver Form 응모 2건, 총 3건의 완료 화면을 확인했습니다. 마지막 응모는 앱이 후보 수집·저장 프로필 입력·대시보드 동의/최종 검토를 연결하고, 제출 완료 화면을 자동 판정해 완료 목록에 기록했습니다. 중간 페이지 인식 오류로 수동 복구와 개발자 재개가 필요했으므로 전체 과정의 무개입 성공 평가는 아닙니다. 앞선 두 건도 개발자 개입이 있었습니다. SNS 내 댓글·좋아요·팔로우 응모와 당첨·경품 수령은 아직 검증하지 않았습니다.

## 시작하기

Node.js 24 이상과 Chromium 실행 환경이 필요합니다. macOS에서 개발·검증했습니다.

```sh
nvm use
npm ci
npm run browser:install
npm run dev
```

[http://127.0.0.1:4317](http://127.0.0.1:4317)을 엽니다. `nvm`을 사용하지 않는다면 Node.js 24 이상을 직접 설치한 뒤 실행하세요.

1. **연결 설정 → Continue with ChatGPT**에서 로그인하고 플랜 사용을 허용합니다. 또는 OpenAI API 키를 저장합니다.
2. 사용할 제공자·계정을 선택하고 **모델 불러오기**를 누릅니다. 계정에서 실제 제공하는 모델 중 선택합니다.
3. **자율 설문 테스트**로 가상 프로필·위임과 여러 페이지의 묶음 실행을 확인합니다. **확인함 포함 테스트**는 모르는 사실 2개를 대시보드에서 한 번에 답합니다. 기존 **AI 브라우저 테스트**도 사용할 수 있습니다. 실제 모델 사용량은 발생하며 경품은 없습니다.
4. **기회 탐색**에서 원하는 조건과 시작점을 고릅니다. 기본은 문화포털 공지 목록입니다. Google 검색이나 다른 공개 목록 주소도 사용할 수 있습니다. 특정 이벤트 URL을 미리 찾을 필요는 없습니다. **새 웹 폼 1건 자동 준비**를 선택하면 원문·폼이 관찰됐고 미참여·기간·과제 조건을 통과한 후보 한 건을 골라 저장된 위임으로 이어갑니다.
5. **프로필·위임 정책**에서 기본 정보와 추천 답변 기준, 재사용 범위, 최종 제출 방식을 저장합니다. 후보의 원문·기간·필수 과제를 확인하고 **응모 준비**를 시작하면 해당 사이트에 한정해 적용합니다. 처음 보는 사실·동의는 **확인함**에 모이며, 답변 후 현재 탭에서 재개합니다. 위임을 끄면 기존 단일 동작 확인 경로로 실행합니다.

SNS 첫 가입·로그인·MFA는 전용 브라우저에서 본인이 진행합니다. 로그인은 지속 프로필에서 재사용합니다. 추가 인증이 나타나면 일시정지하고 직접 처리합니다. Google 검색의 추가 인증에 의존하지 않도록 공개 목록에서 직접 탐색할 수 있습니다.

**SNS·폼 로그인**에서 기본 Chromium 또는 설치된 Google Chrome을 선택할 수 있습니다. 두 전용 프로필의 로그인은 별개이며, 기본 Chromium으로 돌아오면 기존 저장소를 다시 사용합니다. 네이버는 홈 화면으로 열고, 로그인 때 ‘로그인 상태 유지’를 선택한 후 정상 종료·다시 열기로 확인하세요. 유지 여부는 사이트의 세션 정책에도 달려 있습니다. Google이 ‘브라우저 또는 앱이 안전하지 않을 수 있습니다’라고 거부하면 일반 브라우저의 직접 참여 버튼을 사용할 수 있습니다. 이 수동 경로의 로그인은 에이전트와 공유되지 않습니다.

## 현재 기능과 범위

| 기능 | 상태 |
| --- | --- |
| ChatGPT 로그인·플랜 권한·모델 조회·이미지/도구 호출 | 구현, 실제 연결과 가상 응모 2회 확인 |
| OpenAI API 키·제공자 분리 | 구현, 합성 전송 테스트; 실제 API 키 호출 미검증 |
| 보이는 전용 Chromium·지속 프로필 | 구현; 스크린샷·좌표/요소 클릭·스크롤·입력 |
| 공개 목록/웹 검색에서 이벤트 탐색 | 구현; 원문·이미지 근거, 조건, 마감, 선정 인원 저장 |
| 검토 우선순위·중복 방지 | 구현; 우선순위는 당첨 확률이나 기대 수익이 아님 |
| 입력/동작 확인·직접 조작·재개 | 질문·답변·제출 대상을 표시; 원본 JSON은 접힌 상세 보기, 화면 변경 시 승인 무효화 |
| 프로필·위임·답변 재사용·확인함 | 구현; 사이트/질문 범위, 정책 변경 시 기존 위임 만료 |
| 페이지별 계획·묶음 입력·조건부 문항 복구 | 네이티브 폼 구현; 실제 ChatGPT 합성 설문에서 무개입 완료 |
| 제출 결과 불명·재시작 복구 | 구현; 완료 증거 없이 성공 처리하거나 자동 재제출하지 않음 |
| 완료한 응모·진행 확인함 | 경품·접수일·발표 안내·접수 증거를 별도 목록에서 검색; 과거 실행 로그는 접어서 표시 |
| 탐색 근거 전달·공개 정답 조사 | 관측한 원문/유입 경로 재사용, 부족한 퀴즈 근거는 별도 읽기 탭에서 조사 |
| 실제 Instagram·Google/Naver Form 응모 | Naver Form 2건 제출 확인, 그중 1건은 앱이 완료 판정·기록; Instagram 원문 탐색 포함, SNS 내 응모·Google Forms는 미검증 |
| 예약 실행·당첨 발표·쿠폰 관리·파일 첨부·기존 브라우저 연결 | 후속 단계 |

한 번에 브라우저 작업 하나를 실행합니다. 작업별 판단 횟수와 15분 실행 구간을 제한하며 입력/출력 토큰을 기록합니다. 일별 금액 예산이나 예약 실행은 아직 없습니다. 대기 상태에서는 모델을 반복 호출하지 않습니다.

최종 제출 뒤에는 결과 화면을 먼저 보관합니다. 알려진 완료 문구와 연결되지 않으면 저장된 화면의 의미를 한 번 더 판단하고, 제출 의도·시각·출처·새 증거가 맞는지 검사합니다. 결과가 불명확하면 재제출하지 않으며 대시보드에서 **저장된 접수 증거 다시 확인**을 사용할 수 있습니다. 발표 일정이 수집돼도 자동 당첨 조회나 알림이 예약되는 것은 아닙니다.

출처별 접근 조건과 참여 자격을 확인한 범위에서 사용하세요. 새 계정 대량 생성, 인증 우회, 중복 응모, 허위 체험·인증, 타인 반복 태그는 지원하지 않습니다. 페이지나 모델이 지시해도 도구 권한을 바꾸거나 임의 코드를 실행하지 않습니다.

## 데이터와 연결

- 기본 저장 위치는 `~/.local/share/ssal-gpt`입니다. 인증정보, Chromium 프로필, SQLite 작업 기록, 증거 스크린샷은 소스 체크아웃 밖에 둡니다.
- 디렉터리는 `0700`, 비밀정보 파일은 `0600`으로 보관합니다. OS 키체인 암호화는 아직 적용하지 않았습니다. 이 폴더를 공개 저장소에 복사하지 마세요.
- AI에는 현재 작업과 관찰 화면·보이는 텍스트가 전달됩니다. 비밀번호 페이지에서는 관찰을 중단하고 입력 필드는 화면에서 마스킹합니다. 일반 페이지 본문에 표시된 개인정보까지 완전히 자동 제거하는 기능은 아닙니다.
- ChatGPT 플랜과 API 키는 별개 경로입니다. 한도·권한 오류가 나면 멈추며 다른 과금 경로로 자동 전환하지 않습니다.
- 이 앱의 ChatGPT 로그인은 SNS 계정 로그인이나 기존 ChatGPT 대화 접근을 제공하지 않습니다.

환경변수: `SSAL_PORT`(기본 `4317`), `SSAL_DATA_DIR`(체크아웃 밖 경로), `OPENAI_API_KEY`(선택). 기본 실행 명령은 `.env`를 자동 읽지 않습니다. 필요하면 `.env.example`을 참고해 환경변수를 설정하거나 `node --env-file=.env --import tsx src/main.ts`로 실행하세요. 기본 호스트는 `127.0.0.1`이며 공개 서버 배포용 인증은 없습니다.

```sh
npm run check
npm test
npm run test:browser
npm run format:check
npm run build
```

자동 테스트는 임시 로컬 데이터와 합성 모델 전송을 사용합니다. 실제 AI 시각 판단 성공과 구분합니다. 브라우저 테스트는 Chromium 설치가 필요하며, Linux에서는 `npx playwright install --with-deps chromium`으로 시스템 의존성을 함께 설치합니다. 실제 모델 평가는 앱의 테스트 버튼으로 수행합니다.
